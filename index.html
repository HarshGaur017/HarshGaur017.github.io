Selected work

Six systems I own or built from scratch. All production, all at Mulltiply.

01 Hinglish search parser

An LLM query parser that converts natural-language Hindi, Hinglish and Devanagari product queries into a structured Meilisearch query plus a filter expression — transliterating चना दाल → chana dal and detecting colloquial price intent like "500 tak", "1000 ke aaspas", "kitne ka".

Treated as a compiler, not a chatbot: price cues resolve to concrete numeric bounds at parse time, approximate prices expand to ±10% ranges, and a bare number without a price cue is explicitly not read as a price — so the model can't invent filters.

OpenAIMeilisearch Prompt engineeringNode.js

02 ERP integration platform

Owned the connector layer that syncs the platform with the offline accounting software Indian distributors actually run — Marg, Tally, Busy and Zoho, plus Shopify.

Built Zoho's full OAuth flow, Marg item/pricing/order/ledger/invoice sync with batch-wise processing for oversized payloads, and Busy CRUD for items, customers, invoices and stock. Wrote the transform layer that reconciles four incompatible ERP schemas into one internal model.

OAuth 2.0Sequelize XML / RESTIdempotent sync

03 Invoice OCR pipeline

Retailers order from paper invoices and handwritten lists. This turns a photo into structured order lines.

Multi-file upload and parsing, an LLM pass that structures raw OCR text, a preview step before anything is committed, and an ocrTrainingData module I created to capture results for model improvement. Contributed to the Python service behind it.

04 Voice ordering

A zero-typing order path for users with low literacy or low comfort with apps.

Speech → transcript → LLM parser, with automatic language detection, wired through to the cart. Removes the keyboard from the critical path entirely.
